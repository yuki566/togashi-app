# 富樫氏 史跡めぐりWebアプリ

プロジェクトデザイン実践　チーム番号：CCCA-404-5 / E5

富樫氏と野々市市の史跡を題材にした、スマートフォン向けのWebアプリです。
6問・4択のタイプ診断（統治・武勇・信仰・学び）で自分に合うタイプを判定し、タイプに合う史跡を紹介します。

## 画面（必須機能）

| 画面 | 内容 |
|---|---|
| S1 ホーム | 「診断をはじめる」ボタン |
| S2 診断 | 6問（4択）を1問ずつ表示。「戻る」で前の質問へ |
| S3 診断結果 | タイプ名・説明・おすすめスポット3か所 |
| S4 スポット一覧 | 8か所を表示。位置情報を許可すると距離・徒歩時間も表示 |
| S5 スポット詳細 | 写真・解説・出典・住所・地図アプリへのリンク |

追加機能（必須機能の完成後）：スタンプ獲得、スタンプ帳、結果カード

## 使っている技術

- HTML / CSS / JavaScript（フレームワークなし、ビルドなし）
- データは `data/` フォルダのJSONファイル
- 診断結果などは、スマホの中（localStorage）にだけ保存します。サーバー処理や個人情報の収集はありません
- 公開は GitHub Pages（HTTPS）

## フォルダ構成

```
index.html          画面の土台
css/                見た目
js/                 プログラム（診断ロジック、データの読み込み、保存、各画面）
data/               診断の質問、タイプの説明、スポットのデータ（JSON）
images/             自分たちで撮影した写真
```

## ルール（授業の条件）

- 生成AIが作ったコードは、実行前に全員でレビューし、藤本先生に報告します（記録はNotionのレビューログ）
- 生成AIで作った画像・動画は、アプリにもポスターにも使いません
- 写真は自分たちで撮影したものを使います

## 開発の進め方

1. 変更は、`main` に直接ではなく、自分用のブランチで行う
2. GitHub Desktop で「Pull Request」を作る
3. 全員でレビューしてから `main` に取り込む

環境の準備は、Notionの「開発環境の準備」ページを見てください。
